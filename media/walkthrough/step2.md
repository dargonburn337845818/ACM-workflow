# ② 选题 / 导入题目

按 `Ctrl+Alt+A` 打开工作台，有 **3 种方式** 获得题目：

## 方式一：随机选题

「选题」页设置难度区间（800~3500）→ 点击 **随机推荐**；
刷题多后可点 **薄弱点推荐**，从你通过率最低的算法专题中抽题补弱。

## 方式二：URL 导入

「选题」页底部 **通过 URL 导入** 输入框粘贴 Codeforces 题目链接：

```
https://codeforces.com/problemset/problem/1791/E
https://codeforces.com/contest/1791/problem/E
https://codeforces.com/gym/104053/problem/A
```

回车即自动生成 `cpp + 测试配置 + 题面`，重复导入会直接打开已有文件。

## 方式三：比赛一次创建

「CF 比赛」页列出即将开始 / 进行中的 Round → 展开查看题目、榜单与关注
→ 点击 **创建整场比赛** 生成整场比赛的 `contest_{id}_{index}.cpp`，并自动抓取样例。
