# ③ 测试、对拍

打开生成的题目 `cpp`，「测试」视图自动加载样例与题面（含中文翻译按钮），题面和样例分成两个页面。

## 单测

- 顶部切到 **样例** 页：**▶ 运行全部** → 自动编译（自动探测 g++）→ 逐用例运行 → 通过/失败/超时标记
- 每个用例可单独运行；可随时 **取消**；用例编辑后 **自动保存**
- 全过自动标记 **已AC** 并登记刷题记录，状态栏出现「下一题 ▸」保持连刷

## 对拍（通用对拍器）

测试视图切到「对拍」模式：正解 = 当前文件，选择暴力程序 →
「造数据」页只有流水线拼装：一个个添加步骤（单个数/一行多个数/每行两个数/固定文本/换行/重复块/数组/树/图/字符串/排列/自定义脚本），单个数可绑定变量名，重复块可按变量次数重复，每步参数独立保留 →
比对方式可选精确 / Token / 浮点误差 / Special Judge →
循环比对输出，发现不一致立即停止并展示差异数据（可保存为文件）。

> 快捷键：`Ctrl+Alt+A` 打开工作台；更多命令见命令面板（输入 `ACM Workflow`）。
