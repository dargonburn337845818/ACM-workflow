算法节点明细

算法分类质量简介复杂度模板长度
Dijkstra 图论 / 最短路 完整 非负权图单源最短路；优先队列取当前最近点，松弛邻边。 O((V+E) log V) 450
Bellman-Ford 图论 / 最短路 完整 可处理负权边，并检测负环：第 n 轮仍能松弛说明存在负环。 O(V·E) 438
Floyd-Warshall 图论 / 最短路 完整 全源最短路，三重循环枚举中转点；负权可行（无负环）。 O(V³) 271
Kruskal 图论 / 最小生成树 完整 按边权升序加入，并查集判环；边少（稀疏图）时优先。 O(E log E) 589
Prim 图论 / 最小生成树 完整 从任意点开始，每次选连接已选集合的最小边；稠密图用邻接矩阵/堆优化。 O(n²) 朴素 / O((n+m) log n) 堆优化 399
连通块染色 图论 / DFS / BFS 完整 DFS/BFS 遍历相邻同色/可达点，给每个连通块编号。 O(nm) 205
二分图染色判定 图论 / DFS / BFS 完整 黑白染色，若相邻点同色则不是二分图。 O(n+m) 157
简单回溯 图论 / DFS / BFS 完整 递归枚举所有排列/选择，通过剪枝减少无用分支。 O(排列数 × 检查) 149
石子合并 动态规划 / 区间 DP 完整 合并相邻石子堆的最小代价；先枚举区间长度，再枚举分割点。 O(n³)（四边形不等式可优化到 O(n²)） 486
TSP（状压） 动态规划 / 状压 DP 完整 dp[s][i]：已访问集合 s、停在 i 的最短路径；从 0 出发回到 0。 O(2ⁿ·n²) 458
树上最大权独立集 动态规划 / 树形 DP 完整 每个点选/不选两种状态；选了则子树根不能选。 O(n) 324
KMP 字符串 / 模式匹配 完整 利用失配时已匹配前缀的信息（next 数组）线性匹配，不回溯文本指针。 O(n + m) 541
Trie（字典树） 字符串 / 哈希与字典树 完整 用共享前缀的树存储字符串集合，支持插入与查询 O(长度)。 O(|S|) 每次操作 482
字符串哈希（Rolling Hash） 字符串 / 哈希与字典树 完整 把字符串映射为多项式哈希，O(1) 比较任意子串（配合前缀哈希）。 O(n) 预处理 / O(1) 子串比较 422
并查集 (DSU) 数据结构 / 并查集 完整 近似 O(1) 的合并/查找；路径压缩 + 按秩合并保证摊还复杂度。 O(α(n)) 摊还 372
带权并查集 数据结构 / 并查集 完整 在路径压缩时维护每个点到根的距离/权值，可处理“相对关系”问题。 O(α(n)) 摊还 276
位掩码子集枚举 基础算法 / 位运算 完整 枚举 mask 的所有非空子集，常用 sub=(sub-1)&mask 跳过无效状态。 O(3^n)（所有子集的子集） 85
状态压缩 + BFS 基础算法 / 位运算 完整 把状态压缩成二进制，BFS 求最短步数；常用于小规模地图/钥匙问题。 O(状态数 × 转移) 316
矩阵快速幂优化递推 矩阵 / 矩阵快速幂 完整 把线性递推写成矩阵乘法，用快速幂 O(k³ log n) 求第 n 项。 O(k³ log n) 354
