算法分类质量简介复杂度模板长度
Dinic 最大流 图论 / 网络流 完整 BFS 分层 + DFS 多路增广（当前弧优化），最坏 O(V²E)，实际飞快。 O(V²E) 1200
最小割建模 图论 / 网络流 完整 最大流 = 最小割；把收益/代价连到源/汇，割的代价对应答案。 O(Dinic) 378
二分图最大匹配（匈牙利） 图论 / 进阶图论 完整 对每个左部点尝试增广，visited 避免重复。 O(n·m) 304
KM 算法 图论 / 进阶图论 完整 带权二分图完美匹配 O(n³)，维护可行顶标与相等子图。 O(n³) 203
主席树（区间第 k 小） 其他 / 主席树 完整 每个前缀一棵权值线段树，差分求区间内第 k 小；值域离散化。 O((n+q) log n) 684
FHQ Treap（无旋 Treap） 数据结构 / 高级数据结构 完整 用 split/merge 实现插入、删除、区间翻转与第 k 大，无需旋转。 O(log n) 期望 594
莫队（区间不同数） 其他 / 莫队 完整 分块排序询问，指针左右移动维护答案；修改代价必须 O(1)。 O((n+q)√n) 670
斜率优化（CHT） 动态规划 / DP 优化 完整 转移含 i*j 乘积项时，把候选决策看成直线，用单调队列维护凸壳。 O(n) 或 O(n log n) 208
四边形不等式优化 动态规划 / DP 优化 完整 区间 DP 若满足四边形不等式，最优决策点单调，可把 O(n³) 优化到 O(n²)。 O(n²) 219
Andrew 单调链凸包 计算几何 / 凸包 完整 按 x 排序后分别构造上下链；叉积判断转向，O(n log n) 求凸包。 O(n log n) 594
叉积 / 点积判断方位 计算几何 / 向量基础 完整 叉积判断三点转向/面积，点积判断角度与投影。 O(1) 228
最近点对（分治） 计算几何 / 最近点对 完整 按 x 分治，跨中线候选点按 y 排序后只检查邻近点，O(n log n)。 O(n log n) 836
线段相交判定 计算几何 / 线段相交 完整 跨立实验：两端点分居对方线段两侧；再补共线端点情况。 O(1) 667
高斯消元（异或方程组 bitset） 数论 / 进阶数论 完整 用 bitset 优化异或方程组消元，复杂度 O(n³/64)。 O(n³ / 64) 268
扩展中国剩余定理（EXCRT） 数论 / 进阶数论 完整 模数不互素时用 exgcd 两两合并同余方程。 O(k log m) 208
线性基 数论 / 进阶数论 完整 维护一组异或基，可求最大异或和与第 k 小。 O(n log V) 291
中国剩余定理 (CRT) 数论 / 组合数学 完整 求解同余方程组 x ≡ a_i (mod m_i)，模数两两互素；答案对 M=∏m_i 唯一。 O(k log m)（k 为方程个数） 343
AC 自动机 + 矩阵快速幂 字符串 / 多模式匹配 完整 把 AC 自动机状态建成转移矩阵，用矩阵快速幂统计长度为 L 且不含模式串的方案数。 O(S³ log L)（S 为状态数） 316
AC 自动机 字符串 / 多模式匹配 完整 Trie + fail 指针：把多个模式串建成自动机，一次扫描统计全部出现。 O(总长度 × 字符集 + 文本长度) 964
