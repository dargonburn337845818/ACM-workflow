算法节点明细

算法分类质量简介复杂度模板长度
LCA（倍增） 树 / 树上基础 完整 预处理 up[k][u] 倍增祖先，O(log n) 求 LCA。 O(n log n) 预处理 / O(log n) 查询 239
树上差分 树 / 树上基础 完整 路径 u-v 加 1：点差分 diff[u]++, diff[v]++, diff[lca]--, diff[fa[lca]]--；边差分类似。 O(n log n)（需 LCA） 238
树的直径 / 重心 树 / 树上基础 完整 直径：两次 DFS 找最远点；重心：最大子树最小的点。 O(n) 154
线段树（区间和 + 懒标记） 数据结构 / 线段树 完整 四倍空间存区间和与懒标记；区间加、区间求和均 O(log n)。 O(log n) 每次操作 970
树状数组 (BIT) 数据结构 / 树状数组 完整 单点修改 + 前缀和查询，常数极小；区间和 = 两次前缀和之差。 O(log n) 每次操作 338
树状数组求逆序对 数据结构 / 树状数组 完整 离散化后按值域插入 BIT，统计已插入且大于当前数的个数。 O(n log n) 344
ST 表（静态区间最值） 数据结构 / 线段树 完整 预处理 2^k 区间最值，O(1) 回答静态区间最小值；不可修改。 O(n log n) 预处理 / O(1) 查询 503
Tarjan 求 SCC 图论 / 强连通分量 完整 low 值与 dfn 相等即找到一个强连通分量；缩点后图是 DAG。 O(V+E) 718
割点 / 桥 图论 / 进阶图论 完整 Tarjan 的 dfn/low 判定：low[v] >= dfn[u] 为割点，low[v] > dfn[u] 为桥。 O(n+m) 372
拓扑排序 (Kahn) 图论 / 拓扑序 完整 入度为零的结点入队，删除其出边；返回序长 < n 说明有环。 O(V+E) 419
拓扑排序 + DAG DP 图论 / 进阶图论 完整 按拓扑序转移，可求 DAG 最长路、方案数等。 O(n+m) 169
Lucas 定理 数论 / 组合数学 完整 n,m 很大但模数 p 较小时，把 n,m 写成 p 进制逐位求组合数。 O(p log_p n) 128
容斥原理 数论 / 组合数学 完整 多个集合并集大小 = 奇数个交集和 - 偶数个交集和；常用于计数。 O(2^k)（k 为集合数） 155
错排 / 卡特兰数 数论 / 组合数学 完整 错排 D[n]=(n-1)(D[n-1]+D[n-2])；卡特兰 C[n]=C[2n][n]/(n+1)。 O(n) 213
组合数（预处理阶乘） 数论 / 组合数学 完整 预处理阶乘与逆元阶乘，O(1) 回答组合数；p 为大素数。 O(n) 预处理 / O(1) 查询 442
Nim 游戏与 SG 函数 其他 / 博弈论 完整 Nim：异或和为零先手必败。一般公平游戏用 SG 函数记忆化求解。 O(n)（Nim）/ O(状态×转移)（SG） 383
Manacher 字符串 / 后缀结构 完整 线性求每个位置的最长回文半径（# 填充统一奇偶长度）。 O(n) 413
Z-function 字符串 / 模式匹配 完整 对每个位置求与串前缀的最长公共前缀长度，可替代 KMP 做模式匹配。 O(n) 307
后缀数组 (SA) 字符串 / 后缀结构 完整 倍增法对后缀排序；配合 height 数组可做 LCP、子串统计等问题。 O(n log n) 618
数位 DP（不含 4） 动态规划 / 数位 DP 完整 从高位到低位记忆化搜索；tight 表示是否贴上界。统计 [L,R] = f(R) - f(L-1)。 O(位数 × 状态数) 613
轮廓线 DP（简单棋盘状压） 动态规划 / 轮廓线 DP 完整 逐格转移，用二进制表示当前行/列轮廓线状态，常用于棋盘覆盖计数。 O(n·m·2^m) 578
期望 DP（掷骰子） 其他 / 概率期望 完整 从终点逆推：f[i] 表示从 i 到终点还需的期望步数，f[i] = Σ f[下一步]/6 + 1。 O(n) 210
