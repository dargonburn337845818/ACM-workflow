标签说明CF 标签关联模板数
洞察最优解本质 从题目条件中直接看穿关键性质，避免被表层复杂度误导。常见突破口：观察答案的单调性/对称性/极值位置，先猜后证，用反例修正直觉。 0
寻找充要条件 把可行解的存在性/最优性转化为可验证的充要条件。常见手法：把“能否做到”变成“某个不等式/奇偶性/模数条件是否成立”，再构造证明。 0
子任务泛化 先解决子任务或弱化版，再推广到原问题。常见手法：先做 n 小、值域小、无限制的版本，找出规律后再处理一般情况；也常用于 DP 状态设计。 0
固定变量优化 枚举/固定一个变量后，剩余问题变成可快速求解的形式。常见手法：固定左端点/右端点/中位数/某个下标，用数据结构维护另一维的最优值。 0
构造上下界 先证明答案上下界，再构造达到该界的方案。常见手法：用鸽巢/平均/最大最小给出下界，再用显式构造证明可达，避免只猜不证。 0
问题重表述 把原问题等价转化为更熟悉的模型（图、代数、计数等）。常见手法：区间变图论、序列变括号序列、计数变生成函数、最值变二分判定。 0
鸽巢原理 当数量超过类型时，重复不是偶然，而是结构必然；有限状态系统必入循环。 0
轻重分离（大块跟随小块漂移） 把元素按度量分成重集合与轻集合，分别用不同策略维护，复杂度平衡于 B 与 N/B。 0
势能分析法与均摊混沌 构造有上界的势能函数，让昂贵操作消耗“混乱额度”，从而均摊 O(1)。 0
延迟处理与事件批量跳跃 别模拟时间流动，只处理事件；相邻事件间用解析式直接批量跨越。 0
二进制分解与倍增跨越 预计算 2^i 步效果，按二进制拆解任意步数，把 O(K) 迭代降为 O(log K)。 0
维度压缩与位运算并行 把多个布尔状态编码进一个机器字，用位逻辑一次处理 64 个车道。 0
构造的完备性证明（反证法+紧致性） 构造不仅要给出可行解，还要用反证/极小反例堵死所有不行的分支。 0
单调性二分与判定问题转化 不会直接找最优解，就不断“审问”系统：这个值行不行？利用答案单调性二分。 0
根号分治的阈值艺术 给互补算法各划疆域，在阈值处握手；本质是算力资源在不同规模特征上的分配。 0
莫队与顺序优化的离线思维 查询顺序不是约束而是自由度；重新洗牌让相邻查询相似，指针少走路。 0
信息论下界与卡常的本质 逼近理论下界后，真正的对手是缓存、分支预测与指令流水线等物理极限。 0
模运算与哈希碰撞的巧妙规避 哈希必然碰撞；用双模数或随机化把失败概率压到可忽略。 0
互补问题转化（对偶性） 正面攻不下就绕背面：补集替换、最大/最小互换、逻辑取反。 0
矩阵幂与线性递推的封闭形式 线性递推的本质是矩阵在时间轴上的接力；快速幂把时间从累加变成乘法。 0
差分约束与图的路径等价性 “x_i - x_j ≤ c”和“j→i 有一条 c 的边”是同一个抽象结构的不同语言。 0
分治与合并的均摊哲学（CDQ与时间分治） 把左半边的影响打包成整体批量砸向右半边，每个数据每层只处理一次。 0
熵减与有序化：所有算法的共同目标 算法不是解决问题，而是降低状态空间熵，把乱麻理顺到可计算。 0
对称性破缺 在完全对称的分岔路口，主动推倒一边，让系统进入可计算的单行道。 0
量纲匹配的直觉 先用量纲排除法筛掉 90% 算法；看到 n=1e5就知道 O(n²) 必死、O(n log n) 可活。 0
信息瓶颈的极端利用 输出远大于存储时，不物化答案而设计生成器/隐式表示，按需即时展开。 0
问题空间的拓扑变形 把问题像橡皮泥一样翻转、差分、对偶、投影，直到露出熟悉躯壳。 0
随机性的决定性回归 随机不再只是规避最坏情况，而是结构探测器：随机勘探，确定开发。 0
零信息起步的归纳构造 从空/平凡解出发，每一步只做最小局部修复，并用势函数保证步数上界。 0
无标度网络的涌现结构 现实网络度分布服从幂律：少数 hub 主导全局，轻元素只贡献本地噪音。 0
自组织临界性（SOC） 缓慢驱动的系统自发演化到临界态，微小扰动可能触发规模不定的雪崩。 0
长尾效应与“赢得所有，失去所有”的竞争格局 幂律分布下，均匀对待所有元素是低效甚至死刑；必须重量级重服务、轻量级粗处理。 0
涌现 vs 还原：复杂系统的不可拆解性 整体性质无法拆成部分之和；2800+ 后必须找不变量/单调量锚定整体。 0
