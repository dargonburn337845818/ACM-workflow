Link-Cut Tree (LCT) 数据结构 / 动态树 完整 动态树：支持 link/cut/换根/链上信息维护，核心是 Splay 维护的虚实链剖分。 O(log n) 摊还 1290
树链剖分 (HLD) 数据结构 / 树链剖分 完整 重链剖分把树上路径/子树映射成 DFS 序区间，配合线段树维护路径信息。 O(log^2 n) 每次路径操作 611
可持久化数据结构（主席树进阶） 数据结构 / 可持久化 完整 在更新时新建节点保留历史版本，支持查询任意历史版本；主席树是可持久化权值线段树。 O(log n) 每次操作 577
线段树合并/分裂 数据结构 / 高级数据结构 完整 动态开点线段树，合并两棵树或按权值分裂，用于树上颜色计数、区间排序等。 O(n log V) 总合并 138
主席树（区间第 k 小） 其他 / 主席树 完整 每个前缀一棵权值线段树，差分求区间内第 k 小；值域离散化。 O((n+q) log n) 684
后缀数组 (SA) 字符串 / 后缀结构 完整 倍增法对后缀排序；配合 height 数组可做 LCP、子串统计等问题。 O(n log n) 618
后缀自动机（SAM）进阶 字符串 / 后缀结构 完整 在 SAM 上按 parent 树拓扑序累加 endpos 大小，可求每个子串出现次数、本质不同子串等。 O(n) 建图 / O(n) DP 1062
广义 SAM 字符串 / 后缀结构 完整 对多个串建立后缀自动机：插入每个串前把 last 重置为根，或先建 Trie 再 BFS 扩展。 O(总字符数) 987
SAM（后缀自动机） 字符串 / 后缀结构 完整 线性建图；本质不同子串数 = Σ(len[link[i]] - len[i])，两个串 LCS 可在 SAM 上跑匹配。 O(n) 建图 / O(n) 统计 678
FFT 数学 / 多项式 完整 用复数单位根做 DFT/IDFT，O(n log n) 实现多项式乘法。 O(n log n) 936
NTT 数学 / 多项式 完整 在模 998244353（原根 3）下做整数多项式卷积，避免浮点误差。 O(n log n) 730
生成函数 数学 / 组合计数 完整 用形式幂级数表示数列，卷积对应组合计数；常配合 NTT 做多项式求逆/exp/ln。 O(n log n)（配合 NTT） 1277
莫比乌斯反演 数论 / 反演 完整 利用莫比乌斯函数和整除卷积化简 gcd/lcm 类计数问题。 O(n log log n) 筛 + O(√n) 数论分块 429
线性基进阶 数论 / 线性基进阶 完整 线性基进阶：维护区间线性基、支持第 k 小/最大值、可离线合并。 O(n log V) 399
线性基 数论 / 进阶数论 完整 维护一组异或基，可求最大异或和与第 k 小。 O(n log V) 291
半平面交 计算几何 / 半平面交 完整 把每个半平面按极角排序，用双端队列维护交点，求交集凸多边形。 O(n log n) 1401
最小圆覆盖 计算几何 / 圆 完整 随机增量法：依次加入点，若不在当前圆内则重构圆，期望 O(n)。 O(n) 期望 1186
三维凸包 计算几何 / 三维 完整 三维凸包常用增量法：每加入一个点，删除可见面并补上新面。 O(n^2) 1034
支配树 图论 / 支配树 完整 有向图从源点出发，求每个点被哪些点支配；Lengauer-Tarjan 算法 O((n+m)α)。 O((n+m) α(n)) 1202
点分治/边分治 图论 / 树分治 完整 每次找树的重心，统计经过重心的路径，再递归子树，总复杂度 O(n log n)。 O(n log n) 375
动态图连通性（离线） 图论 / 离线动态图 完整 用线段树分治把每条边的存活区间挂到线段树节点，配合可撤销并查集回答离线连通性。 O((n+q) log^2 n) 1339
仙人掌 / 圆方树 树 / 进阶树论 完整 静态建圆方树：环建方点，把仙人掌转成树后跑树形 DP。 O(n+m) 462
插头 DP 动态规划 / 插头 DP 完整 棋盘连通性/回路计数问题：用括号序列或最小表示法表示轮廓线上的插头状态。 O(n·m·状态数) 1727
DP 套 DP 动态规划 / DP 套 DP 完整 把内层 DP 的转移表/结果作为外层 DP 的状态，常用于计数满足某 DP 性质的串/方案。 视内层状态数而定 746
分治 DP 动态规划 / 分治 DP 完整 当 dp 转移满足决策单调性时，用分治确定最优决策点，复杂度 O(n log n·calc)。 O(n log n · cost) 316
斜率优化（CHT） 动态规划 / DP 优化 完整 转移含 i*j 乘积项时，把候选决策看成直线，用单调队列维护凸壳。 O(n) 或 O(n log n) 208
轮廓线 DP（简单棋盘状压） 动态规划 / 轮廓线 DP 完整 逐格转移，用二进制表示当前行/列轮廓线状态，常用于棋盘覆盖计数。 O(n·m·2^m) 578
上下界网络流 网络流 / 上下界网络流 完整 把每条边的下界先流满，再建超级源汇跑附加网络判断可行流/最大流。 O(maxflow) 1412
最小费用最大流 网络流 / 费用流 完整 每次用 SPFA/Dijkstra 找单位费用最短的增广路并增广，累加费用。 O(F·E log V) 1152
