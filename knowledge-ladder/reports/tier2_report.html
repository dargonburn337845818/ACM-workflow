构造算法 基础算法 / 构造 完整 利用奇偶性、模运算或特殊性质直接构造一组满足条件的解。 O(n) 或 O(1)（视题目） 138
反悔贪心（带堆维护） 基础算法 / 贪心 完整 当前贪心选择可能被更优解替换，用小根堆维护已选集合中“反悔代价最小”的元素。 O(n log n) 326
排序后取最值（基础贪心） 基础算法 / 贪心 完整 先按某个关键字排序，再顺序取当前最优值；适用于排序后直接选最大/最小的基础贪心。 O(n log n)（排序） 208
唯一分解定理 数论 / 进阶数论 完整 每个正整数可唯一写成质因数乘积；试除分解 O(√n)。 O(√n) 246
线性筛（欧拉筛） 数论 / 素数筛 完整 每个合数只被最小质因子筛掉一次，同时可求最小质因子与欧拉函数。 O(n) 284
费马小定理求逆元 数论 / 快速幂与逆元 完整 模数为素数 p 时，a 的逆元为 a^(p-2) mod p。 O(log p) 74
欧拉函数 数论 / 欧拉函数 完整 φ(n) = n × ∏(1 - 1/p)；分解质因数 O(√n) 单点求，线性筛可批量求。 O(√n) 单点 / O(n) 批量 681
扩展欧几里得 (exgcd) 数论 / 快速幂与逆元 完整 求解 ax + by = gcd(a,b) 的一组整数解；x 即 a 模 b 的逆元（互素时）。 O(log min(a,b)) 238
0/1 背包 动态规划 / 线性 DP 完整 每件物品最多选一次，滚动数组倒序枚举容量实现一维空间。 O(n·W) 252
完全背包 动态规划 / 线性 DP 完整 物品无限，滚动数组正序枚举容量即可重复选取。 O(n·W) 218
LIS（最长上升子序列） 动态规划 / 线性 DP 完整 求序列中最长的严格递增子序列长度；tail 数组维护各长度末尾最小值。 O(n log n) 223
LCS（最长公共子序列） 动态规划 / 线性 DP 完整 求两个序列的最长公共子序列长度，经典二维 DP。 O(n·m) 315
栈（基础） 数据结构 / 栈 完整 后进先出，常用 vector 模拟；典型应用括号匹配、表达式求值。 O(1) 入栈/出栈 82
队列（基础） 数据结构 / 队列 完整 先进先出，BFS 与拓扑排序的基础容器。 O(1) 入队/出队 56
单调栈 数据结构 / 栈 完整 维护单调递减栈，O(n) 求每个元素右侧第一个更大元素（存下标）。 O(n) 296
单调队列（滑动窗口） 数据结构 / 队列 完整 窗口滑过数组，队头为窗口最大值；过期下标从队头弹出。 O(n) 351
堆（Top-K） 数据结构 / 堆 完整 小根堆维护前 K 大：比堆顶大就替换，堆内即答案。 O(n log k) 267
