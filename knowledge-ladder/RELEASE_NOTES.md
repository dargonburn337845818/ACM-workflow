# Knowledge Ladder v1.0.6

## 产品简介

Knowledge Ladder 是一款面向算法竞赛训练者的拆题引导工具。  
它通过固定的四步思考链，帮助你在写代码前先确认数据形状、数据是否变化、运算规则和数据规模，训练拆题能力，而不是死记模板。

## 核心功能

- 四步拆题引导：打开即用，移动端与桌面端一致
- 拆题流程图：完成后以流程图展示思考路径
- 建议方向：根据答案推荐算法方向，并可查看详细解释
- 算法模板库：覆盖 8 档难度，附算法信息、复杂度与 C++ 模板
- 信息论导论：四操作、四阶段、数据规模速查
- 学习进度管理：记录已掌握知识点

## 桌面端体验

- 深色亚克力主题：清晰、轻盈，适合长时间阅读
- 左侧导航集中排布，支持自由缩放
- 拆题结果以流程图呈现，逻辑一目了然
- 支持个性化壁纸：
  - 视频：MP4 / WebM / MOV / M4V
  - 动态图：GIF
  - 静态图片
  - 有壁纸时透出背景，无壁纸时保持默认亚克力

## 支持平台

- Android（APK）
- Windows（桌面版 EXE）
- 附带 Wallpaper Export 壁纸导出工具

## 使用方式

1. 打开进入拆题引导
2. 依次选择数据形状、是否变化、运算规则、数据规模
3. 查看流程图与建议方向
4. 进入引导式思考，或前往算法模板学习对应内容
